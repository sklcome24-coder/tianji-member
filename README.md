# 自學中醫、紫微斗數、梅花易數、六爻卜卦、玄空飛星 應用學習平台

把 [tianji-platform](https://github.com/sklcome24-coder/tianji-platform) 的四套工具（經方辨證、天紀紫微・易卦、玄空星卦合參、六爻禪解）放到會員制之後，加上：

- 會員註冊／登入／Email 驗證／忘記密碼（沿用 realty-match 已驗證的寫法）
- **每日 AI 額度**：免費會員每日 3 次、付費會員每日 60 次（環境變數可調），主機失敗不扣次數
- **綠界付費方案**：月繳 NT$299、年繳 NT$2,990（環境變數可調），到期不自動續扣
- **經方工具的學習用途同意書**：三項逐條勾選，留存時間與 IP
- **管理後台**：會員數、付費數、AI 用量、營收、贈送天數、停權

## 工具頁一行都不用改

工具頁原本會先連 `127.0.0.1:8765`，連不上就讀 `backend.json`。會員站在 `/tools/backend.json` 回傳 `{"api":"/kb"}`，所以工具的 AI 請求會自動走會員站的 `/kb` 代理：

```
瀏覽器（工具頁） ──/kb/gemini──▶ 會員站：驗登入 → 驗同意書（經方）→ 扣額度 ──▶ 知識庫主機（換上後端金鑰）
```

- 使用者不需要、也看不到後端通行密語，原本的「設定連結 #k=…」在會員站用不到
- 額度用完時回傳 Gemini 形狀的提示訊息，經方頁與紫微頁都能直接顯示原因
- `/kb/tianji`（查原著段落）不計額度；`/kb/gemini` 才計
- 伺服器不記錄請求內容（可能含病況描述）；經方病歷仍只存在使用者瀏覽器

工具更新流程不變：照舊在 tianji-platform 改、推送，會員站重新部署時 `scripts/sync-tools.sh` 會抓最新版。

## 本機開發

```bash
npm install
sh scripts/sync-tools.sh          # 抓工具頁到 ./tools
KB_BACKEND_URL=http://127.0.0.1:8765 KB_BACKEND_KEY=你的密語 npm start
# 開 http://localhost:3460
npm test                          # 端對端測試（假知識庫）
```

開發模式下購買會跳出「模擬付款完成」選項，不必真的刷卡。

## 部署（Zeabur / Railway / Render）

1. 推上 GitHub（私有 repo）→ 平台選 Deploy from GitHub，會自動用 `Dockerfile`
2. **掛 Volume 到 `/app/data`**：會員資料庫 `members.db` 在這裡，沒掛的話重新部署會清空
3. 照 `.env.example` 填環境變數（至少 `NODE_ENV`、`BASE_URL`、`APP_SECRET`、`ADMIN_EMAIL`、`ADMIN_PASSWORD`、`KB_BACKEND_URL`、`KB_BACKEND_KEY`）
4. 綁網域，打開 `https://網域/healthz` 應回 `{"ok":true}`
5. 每日備份 `/app/data/members.db`

## 上線前必辦（需要你本人處理）

- [ ] **知識庫主機搬上雲端**：目前 RAG 後端在你的 Mac 上、走臨時 Cloudflare 隧道，Mac 關機或斷網時付費會員就用不了 AI。收費前要先有穩定主機與固定網址
- [ ] **綠界正式特店**申請，填 `ECPAY_*` 四個變數
- [ ] **SMTP**（Gmail 應用程式密碼或 SendGrid），否則驗證信寄不出去
- [ ] **退費政策**與完整服務條款、隱私權政策（建議律師審閱），補到首頁「服務條款摘要」
- [ ] **成本核算**：以「每次 AI 呼叫成本 × 付費會員每日上限 60 次」估算最壞情況，確認 NT$299 月費仍有利潤
- [ ] **法律風險（請務必讀）**
  - 經方工具會針對個人症狀產出處方。收費後被認定為醫療行為的風險上升（醫師法第 28 條）。本站已加上同意書、急症提示、「醫師參考文件」，但這些是降低風險，不是消除風險
  - 倪海廈老師的著作權仍屬原權利人。收費的定位必須是「系統與 AI 運算服務費」，不能是販售倪師教材；知識庫回答以短篇引用加出處為限。若能取得漢唐中醫或權利人授權最好
  - 原 tianji 首頁寫明「非營利」，會員站不沿用該首頁；兩邊對外說法要一致
